# 運用・セキュリティ・検証境界

## 作業状態を区別する

- Connect：ChatGPT上にアプリが表示される。
- Tool Call：接続先のMacで実ツールが動き出力が返る。
- Read：Macの個別ファイルやDiaタブを正しく読める。
- Write：対象に実際の変更を行い、読み戻して確認する。
- UI Handoff：操作中のタブを実ユーザーが目で確認し、本人がボタンを押せる。
- Submit：同じタブで本人承認の操作を**一度だけ**実行する。
- Receipt：送信結果・完了画面を同じタブに保持し、別の受付証拠を確認する。

これらは独立した確認項目です。AppleScriptによるタブの列挙に成功しても、フォーム入力や申込完了まで成功したことにはなりません。

## 公開しないもの

- MCPの実接続URL（認証パス付き）
- Cloudflare Tunnelの秘密鍵、証明書・資格情報
- Relayの秘密設定、プリンシパルリスト、dashboard鍵
- 実際のMacユーザー名、メール、ブラウザの個別タブURL
- 他AIの未コミット作業ツリーの内容（権限と範囲の確認前）
- 保存したMCPの操作ログやAPI資格情報

## 運用の目安

- URLが漏れた疑いがあれば失効して発行し直す。
- 既存のAIと同じMacを操作する時は、画面の取り合いに気をつける。
- フォーム送信、削除、購入、支払いは、本人が確認してから実行する。
- タイムアウトした送信は、結果を確かめてから再実行する。
