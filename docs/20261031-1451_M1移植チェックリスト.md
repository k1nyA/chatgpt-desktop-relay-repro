# 2台目のMacへの追加

[README](../README.md) の手順をそのMacでもう一度実行するだけです。URLはMacごとに発行されるので、別のMacからコピーするものはありません。

1. [導入](../README.md#1-導入) を実行する。
2. `desktop-relay` で起動し、`desktop-relay url` でURLを取る。
3. ChatGPTに、Macが分かる別名（例：`DesktopRelayM1`）で追加する。既存のアプリはそのまま残す。
4. 新しいチャットで `hostname` を実行し、狙ったMacの名前が返ることを確認する。

同じMacでRemote Desktop Commanderを動かしていても、並行して使えます。M1ではRemote Desktop Commanderを動かしたまま導入し、ChatGPTからの端末実行まで確認しました。

## 確認の順番

| 確認 | 見るところ |
| --- | --- |
| 接続 | ChatGPTにツールが表示される |
| Macの識別 | `hostname` が狙ったMacの名前になる |
| 読み書き | ファイルを読める・書いて読み戻せる |
| Dia | フラグ付きで起動したDiaのタブを操作できる |
| 停止 | Ctrl+C後にChatGPTから届かなくなる |
